本目录下的五张表情图为 **Yuuyuko-uu 自绘**，来自
[dsh-feiyu-mood](https://github.com/Yuuyuko-uu/dsh-feiyu-mood)（本项目注释所记的
0.7.6 时期）。原仓库 README 第九节「换掉示例图片」与《Yuuyuko-uu 插件许可 1.2》
开头「还有我做的图」均说明这些图由原作者本人绘制，**不是第三方画师素材**。

| `face-good.png` | 开心（62–79） |
